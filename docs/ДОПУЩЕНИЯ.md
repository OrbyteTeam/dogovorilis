## ЗАДАЧА_01 — решения по ходу (20.09.2026)

### Шаг 0, окружение
- 20.09 · Сертификаты Минцифры взяты **из связки ключей macOS**, а не с gosuslugi.ru/crt · страница `https://www.gosuslugi.ru/crt` с этой машины не открывается (HTTP 000, DNS/сеть), а корневой и выпускающий сертификаты уже есть в системном доверии: `security find-certificate -a -c "Russian Trusted Root CA" -p`. Выпускающий взят прямо из TLS-цепочки `platform-api2.max.ru`. Результат склеен в `certs/russian_trusted_bundle.pem` и проверен `openssl verify -CAfile` против живого серверного сертификата — цепочка сходится · если сертификат сменится, пересобрать тем же способом; отпечатки SHA-256 записаны комментариями в самом PEM.

## ЗАДАЧА_02E — сервер через API Timeweb, деплой

### Сервер и деньги
- 21.09 · Сервер создан **через API**, не через панель: пресет 2453 «Cloud-50» (2 × 3.3 ГГц, 4 ГБ, 50 ГБ NVMe), зона `spb-3`, Ubuntu 24.04, id `9156435` · все id проверены `GET`-запросами до создания и совпали с ожидаемыми · цена 1 000 ₽/мес подтверждена `GET /api/v1/account/services/cost` **после** создания.

## ЗАДАЧА_03 — правки по аудиту

### A–B: ответ карточкой, сделка-пример
- 22.09 · **Ответ на любую кнопку карточки — перерисованная карточка**, реакция — заметкой над ней; `syncCards` пропускает нажатую · `POST /answers` правит нажатое сообщение: текстовый ответ либо стирал кнопки (E1/E9/E13, запрос ввода, «Квитанция PDF»), либо сам затирался следующей правкой — так в настоящем MAX пропадали реквизиты перевода (аудит §3.1) · если MAX начнёт показывать ответ отдельным сообщением — заметки станут лишними, но ничего не сломают.
- 22.09 · Реквизиты перевода живут **в тексте карточки клиента**, отдельного сообщения P1 больше нет; «Получил(а) / Не вижу» — и в карточке исполнителя, и в уведомлении P2 · правка карточки не даёт push, поэтому P2 остаётся; P1 был бы затёрт той же правкой · —
- 22.09 · Подтверждения необратимых действий («Отменить», «Отказаться», «Закрыть без чека») показываются **поверх карточки** с кнопками [Да] [↩️ Назад]; у исполнителя при отмене — [Без причины] [↩️ Не отменять], и «Назад» снимает ожидание причины · найдено при разборе: передумавший исполнитель оставался в ожидании причины на 30 минут, и любая его реплика отменяла сделку · —
- 22.09 · «Открыть» вне карточки (уведомление, список `/deals`) и повторный вход клиента по ссылке присылают карточку **новым сообщением вниз**, старое сообщение становится указателем «↓ Карточка — ниже» без кнопок; на само уведомление отвечаем `/answers` без `message` · правка на месте где-то выше по ленте выглядела как «ничего не произошло» · если MAX отвергнет пустой ответ — в логе будет `пустой ответ на «Открыть» отклонён`, карточка всё равно придёт.

### F–G: платежи и безопасность
- 22.09 · **Поздний succeeded учитывается** (F1): локальные `expired`/`canceled` значат «мы перестали ждать», а не «денег не будет».
