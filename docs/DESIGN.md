# DESIGN.md — дизайн-токены и правила интерфейса

Источник токенов: `@maxhub/max-ui@0.5.0/dist/styles.css` (значения сняты 20.09.2026, см. `../research/max_miniapps.md` §3.4),
документация https://dev.max.ru/ui, Figma-гайдлайн `MAXUI-Figma.fig` в репозитории max-ui (не открывался — при расхождении
приоритет у CSS пакета). Ориентир по стилю — интерфейс MAX и цифровые сервисы Москвы: спокойные поверхности, один акцент,
крупные тап-зоны, минимум декора.

Правило №1: мини-приложение использует **компоненты MAX UI и его CSS-переменные**, а не собственные цвета. Свои компоненты
(табы, модалка, тост, сегмент-контрол — их в MAX UI нет) строятся только на переменных ниже.

## 2. Типографика

Шрифт: системный — iOS `-apple-system, system-ui, "Helvetica Neue", Roboto, sans-serif`; Android `Roboto, sans-serif`
(`--family-base`, задаётся `platform`). Никаких веб-шрифтов.

| Стиль (MAX UI `Typography`) | Размер/высота (rem) | Вес | Где у нас |
|---|---|---|---|
| hero | 1.75 / 2 | 600 | не используем |
| header (`Typography.Headline large-strong`) | 1.5 / 1.75 | 600 | заголовок экрана («Новая сделка») |
| subheader | 1.25 / 1.5 | 600 | «Карточка создана» |
| title (`Typography.Title`) | 1.0625 / 1.5 | 600 | название сделки в списке |
| body (`Typography.Body medium`) | 1 / 1.25 | 400 (strong 500) | основной текст, поля |
| detail | 0.9375 / 1.25 | 400 | подписи в карточке |
| description | 0.8125 / 1 | 400 | подсказки под полями |
| label | 0.75 / 1 | 400/500 | подписи полей, overline |
| tag / note | 0.6875 / 1 · 0.625 / 0.75 | 400/500 | бейджи («демо», «тест») |
| action-large / medium / small | 1.0625 / 1 / 0.875 | 500 | текст кнопок |
Суммы — `Typography.Title` с табличными цифрами (`font-variant-numeric: tabular-nums`), формат `1 500 ₽`.

## 4. Компоненты — что из MAX UI и как

| Нужно | Берём | Пропсы/замечания |
|---|---|---|
| Кнопка действия | `Button` | `variant="primary" size="large" stretched loading` для главного действия; `secondary` — второстепенное; `destructive` — отмена сделки |
| Иконка-кнопка (копировать) | `IconButton` | `variant="secondary" size="small"` |
| Строка списка | `CellSimple` | `title`, `subtitle`, `overline` (#id), `after` (`Counter` с суммой), `showChevron`, `surface="island"` |
| Действие в списке | `CellAction` | `mode="primary" \| "destructive"` |
| Группа строк | `CellList` | `mode="island"` + `CellHeader titleStyle="caps"` |
| Поля | `Input`, `Textarea` | `size="large"`, `hint` для подсказки/ошибки; ошибка — текст hint цветом `--text-negative` |
| Переключатели | `Switch`, `Radio` | режим чека — `Radio`; рейлы — `Switch` |
| Загрузка | `Spinner` | по центру `Panel centeredX centeredY` + текст «Загружаем…» |
| Бейджи | `Counter` | `variant="attention"` для «нужно действие», `variant="mute"` для «демо»/«тест» |
| Аватар сторон | `Avatar.Container` + `Avatar.Text` | градиент по хешу имени |
| Контейнеры | `Panel`, `Container`, `Flex`, `Grid` | `Panel mode="secondary"` для фона экрана |
Своё (на токенах): **табы** (список фильтров — горизонтальный скролл чипов: фон `--background-secondary`, активный —
`--button-primary` с белым текстом, радиус 20 px, высота 36 px); **сегмент-контрол** предоплаты (Нет / 30 % / 50 % / Своя);
**тост** (низ экрана, `--background-card`, тень, 3 с); **модалка подтверждения** («Отменить сделку?») — `--background-overlay`
+ лист снизу радиус 16 px; **datetime** — нативный `<input type="datetime-local">`, стилизованный как `Input`.

## 5. Состояния и обратная связь (критерий UX 20 %)
- Каждый экран: загрузка → данные / пусто / ошибка с кнопкой «Повторить». Пустые состояния — короткий текст + действие.
- Кнопка после нажатия: `loading` до ответа; повторное нажатие заблокировано; после успеха — тост «Готово» и переход.
- Ошибка сети: тост «Нет связи. Проверьте интернет и повторите» + кнопка «Повторить»; ошибка 401 — экран W0 (§7.1 SPEC).
- Валидация — при потере фокуса и при отправке; текст ошибки конкретный («Сумма от 1 до 1 000 000 ₽»).
- Haptic: `notificationOccurred('success')` после создания сделки, `('error')` при ошибке (только mobile).
- Тёмная тема — автоматически через MAX UI; свои компоненты обязаны использовать переменные, проверка в обеих темах.

## 6. Карточка в боте (не HTML — текст + кнопки)
Порядок строк фиксирован (SPEC §6.4): статус-эмодзи + название + #id → статус → 📌 что → 🗓 когда → 💰 сумма/предоплата
→ ↩️ правило → 👤 стороны → строка оплаты → строка чека. Жирным — только название и суммы. Не более 12 строк и 1 200 символов.
Эмодзи статусов: ⏳ ожидание · ✏️ изменения · ⛔ отказ · ⌛ истекло · 💳 оплата · 📅 запланировано · 🔍 приёмка · ⚠️ замечания ·
🧾 чек · ✅ закрыто · 🚫 отмена · 🧪 демо. Кнопки: главное действие — первым в первом ряду; деструктивное («Отменить») — последним рядом.
Названия кнопок — глагол в повелительном наклонении или результат: «Подтверждаю», «Принимаю», «Я перевёл(а)», «Получил(а)».

## 7. Доступность
Контраст текста на фоне ≥ 4.5:1 (значения MAX UI это обеспечивают: `#060708` на `#fff`, `#fff` на `#17181c`);
акцент `#007aff` на белом — 4.0:1, поэтому акцентный цвет только для крупного текста/кнопок с белым текстом, не для мелких подписей.
Фокус-стили не отключаем; все интерактивные элементы — кнопки/ссылки, не `div`.
